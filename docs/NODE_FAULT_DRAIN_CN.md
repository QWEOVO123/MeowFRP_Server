# 控制面故障隔离与隧道排空（2026-10-05）

## 故障流程

- 中心每秒检查 MySQL 连接、关键表读权限及写可用性。首次失败暂停新登录、租约与新代理注册；已有客户端心跳返回可等待的 `node_recovering`，不因短暂抖动强制登出。
- 连续失败满 10 秒，判定中心数据库故障。中心自身返回“节点异常”，通过现有 mTLS 双向流直接广播 `controller_state`；心跳确认也带故障位。不依赖故障数据库排队通知。
- 中心保存全部已注册节点的内存目录（包括离线节点），包含证书序列号、状态及节点资料。启动加载、定期核对、注册/删除/命令确认更新；删除的节点有内存撤销标记，故障回退不能恢复已撤销证书。
- 边缘控制连接断开、心跳超时、中心故障通知或本地 data 文件不可用时，停止新登录、新租约和新代理。物理断线时先封住接入，再等旧应用线程退出并事务清空用户/Token/资源/DPI 缓存。
- 已认证客户端与 FRP 运行租约使用独立的内存运行态。这里只保留现有会话的 Token 指纹、设备标识、运行租约及最后已验证的 DPI 策略，不用于新登录；原用户缓存确实被清空。
- 已注册代理继续运行，不因控制面故障调用停止 frpc、撤销租约或关闭流量连接。已有代理所需的 Ping/NewWorkConn/NewUserConn 校验走运行态，不查询已清空缓存或故障 MySQL。
- 客户端仍有代理时只发一次警告，拒绝新端口；代理数归零后，下一次客户端心跳下发已有 `reauth` 命令。计数不使用客户端上报的 `frpc_running`，也不使用 TCP 流量连接数。
- 数据库恢复后重新开放中心接入；已经进入故障排空的客户端仍须关闭现有端口后重新登录。发生正式故障的边缘重新清缓存、上报确认、中心清关联表、完成分页基线和最终确认后，才接纳新会话。不足 10 秒的短暂数据库错误不额外重置所有在线边缘缓存。

## 代理数的来源

内嵌 FRPS 源码新增生命周期接口：成功执行代理 `Run`、加入代理管理器后才加一；实际关闭监听器后才减一。使用 `run_id + proxy_name` 去重，按 Token/设备和租约建立计数索引。

新代理注册与故障切换使用读写锁栅栏：正在成功注册的代理先完成计数，再进入排空；进入排空后不能在“计数为零”与登出之间又成功开放一个端口。端口闲置、UDP 无流量、TCP 没有访客都不算关闭端口。

## 同步与上报

- 用户缓存仍使用中心多对多关系及双向索引、事务性脏记录、分页/分片/ACK。重复同世代确认和已过时的确认不会清掉当前会话；超大定向批次有显式限制，不会把未分页到的用户误删。
- 全局 IP 正常变更只发送新增/变更 IP 和删除列表，以节点最后确认的黑名单为比较基准。初始/重连基线全量下发。全局与单节点封禁分开存储，解除某一来源不能解除另一来源。
- 心跳只保活，不上传客户端、连接、流量或日志。只有 Web 中“拉取数据”才请求边缘报告。修改/踢出后的界面不再隐式拉一轮报告。中心本地客户端仍按原实时刷新逻辑处理。
- 心跳时间落库、遥测、事件和命令结果落库移到有超时的独立 worker。遥测写库失败返回本次拉取失败并记录日志，不掐断 mTLS。事件只有实际持久化的部分才确认，未确认数据保留在边缘硬盘。

## 配置命令不是用户缓存

运行参数、权限以及高级设置配置命令保留待执行记录，不再因离线超过 10 分钟失效。使用中心单调版本号以及边缘本地已应用版本，过时配置不能覆盖新配置，旧 ACK 也不能回滚中心目录。进程崩溃留下的 `executing` 幂等命令可以重试，持久化结果失败会返回可重试状态。

用户缓存清空不删除节点自身配置、本地封禁、事件、命令去重及配置版本。已被旧版本标为 `failed` 的过期配置不会擅自重放，需要重新保存。恢复中心数据库旧备份时应同步核对命令版本，不能把版本计数回退当作正常增量更新。

## 升级与边界

必须升级中心及全部边缘。新增 `admission_protocol=1` 能力标记，老边缘的黑名单采用全量兼容下发；正式数据库故障时会断开不支持故障通知的旧边缘流以拒绝新接入，但旧边缘不能提供本版的保隧道保障。

Qt 客户端/frpc 无需更新，复用已有警告与远程登出命令。服务端二进制含修改后的内嵌 FRPS，不需要单独安装 frps。

本流程保证的是不因控制面/数据库故障主动停止数据面；服务器断电、进程退出、FRP 自身的数据连接断开仍然会断隧道。客户端用户主动停止/重启 frpc 也会关闭其端口；现有 Qt 的“关闭单条”会重建剩余隧道，故障期无法重建新代理，请在故障期间使用关闭全部或等待恢复。

手动关闭内嵌 FRPS、改用外部未接入生命周期接口的 frps，无法权威确认端口已全部关闭，本版会保守地不自动强制登出。默认内嵌 FRPS 开启，FRP TLS 默认仍关闭；mTLS 管理通道保持现状。

旧版本 `controller_command` 记录没有保存原始 scope，无法可靠区分历史全局封禁与单节点封禁。本版不猜测删除历史封禁；如果旧版全局解封仍有节点残留，请在该节点执行一次单节点解封。新全局 API 不再写这种混合来源。
